## Overview
This project analyzes employee salary patterns and identifies the main factors that influence compensation. A Random Forest Regressor is used to predict salary based on available features.

## Problem Statement
Organizations often need to understand how salary varies by:
- experience level
- educational background
- role and department
- employee age

This project helps to explore these patterns and build a predictive model for salary estimation.

## Dataset
The dataset used in this project is stored as `data1.csv` and contains employee-related attributes such as:

- Experience
- Education
- Role
- Department
- Age
- Salary
